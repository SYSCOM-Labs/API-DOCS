#### A.4.1 JSON_EventNotificationAlert_cidEvent

Mensaje JSON con la información de un evento CID.

**Descripción de Campos del Mensaje:**

| Campo | Requerido | Tipo | Descripción |
| ----- | --------- | ---- | ----------- |
| deviceSerial | Requerido | String | Número de serie del dispositivo. |
| triggerTime | Requerido | String | Hora en que se disparó la alarma, en formato de hora ISO 8601 (es decir, `"yyyy-MM-ddThh:mm:ss"`). |
| eventType | Requerido | String | Tipo de evento que dispara la alarma; aquí debe ser `"cidEvent"`. Longitud máxima: 128 bytes. |
| eventDescription | Requerido | String | Descripción del evento; aquí es `"CID event"`. |
| isVideo | Opcional | Integer | Tipo de archivo: 0 (sin archivo de video, aunque puede existir imagen), 1 (archivo AVI), 2 (archivo MP4). |
| relationId | Opcional | String | ID de correlación relacionado con la alarma de revisión de video. |
| CIDEvent | Requerido | Object | Información del evento CID. |
| CIDEvent.code | Requerido | Integer | Código del evento CID. |
| CIDEvent.standardCode | Opcional | Integer | Código estándar del evento CID. Solo es válido para CID V3.0 y posteriores. |
| CIDEvent.description | Opcional | String | Tipo de evento CID. |
| CIDEvent.system | Opcional | Integer | Número de partición. Cuando hay varias particiones, indica el número de la primera; para las demás, consulte `partitionNo`. |
| CIDEvent.systemName | Opcional | String | Nombre de la partición. |
| CIDEvent.zone | Opcional | Integer | Número de zona. |
| CIDEvent.zoneV30 | Opcional | Integer | `zoneV30 = zone + 1`. |

## Notas del laboratorio SYSCOM

> **Notas:**
> - Esta sección no forma parte del PDF. Recoge lo observado al probar la OpenAPI con el [OpenAPI Lab](./demos/OpenAPI-Lab/README.md).

### Prefijos de código

| Prefijo | Ámbito |
| ------- | ------ |
| LAP | OpenAPI / cuenta / parámetros / token |
| EVZ | Dispositivo / red / cifrado / comando |
| VMS | Servicios de video / audio en la nube |
| NO_SESSION / BAD_PATH / PROXY_ERROR | Solo el laboratorio SYSCOM (no los devuelve Hik-Partner Pro) |

### Códigos observados que no están en A.1

| Código | Significado |
| ------ | ----------- |
| VMS050020 | Cut-in de audio fallido (convergence-vms-video). Suele deberse a función, firmware o licencia del equipo |
| VMS050028 | Nombre de archivo de audio con caracteres especiales |

### Pistas de audio

| Código | Acción sugerida |
| ------ | --------------- |
| EVZ20007 | El altavoz debe estar en línea |
| EVZ20015 | Solo IP Speaker categoría 12 / subtipo 19 |
| EVZ60020 | Firmware sin el comando; actualizar o probar en HPP |
| VMS050028 | Nombre alfanumérico, guion o guion bajo; sin espacios ni tildes |
| VMS050020 | Payload aceptado pero el altavoz no reproduce; verificar función y `customAudioID` de ese serial |
| EVZ10001 | `audioLevel` [0,15], `audioVolume` [0,100], `pace` [0,100] |
