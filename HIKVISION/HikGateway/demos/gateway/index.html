HIK·GATEWAY
Conéctese a un Hik DeviceGateway on-premise para gestionar dispositivos, explorar la API ISAPI y ver video en vivo. La autenticación HTTP Digest la resuelve el proxy incluido.
Las credenciales se guardan solo en este navegador (localStorage) y se envían por petición al proxy. Nunca se escriben en el repositorio.
