# HIKROBOT — Integraciones disponibles

Documentación técnica de las plataformas y APIs de **Hikrobot** distribuidas por **SYSCOM**.

> **Sobre la marca.** Hikrobot (Hangzhou Hikrobot Co., Ltd.) es un fabricante de robótica y visión artificial industrial: robots móviles autónomos (AMR/AGV) y su software de gestión logística, cámaras inteligentes, lectores industriales de códigos y sensores de visión. Es una empresa independiente de Hikvision, por lo que se documenta como marca aparte dentro del catálogo de SYSCOM.

## Plataformas

| Plataforma | Descripción | Estado |
| ---------- | ----------- | ------ |
| [RCS — Robot Control System](./RCS-Robot-Control-System/README.md) | API REST del RCS para orquestar una flota de robots AMR/AGV de logística "goods-to-person" desde un host (WMS/ERP): tareas de transporte, estado de robots, ubicación de anaqueles y callbacks | ✅ Disponible |
