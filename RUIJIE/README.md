# RUIJIE — Integraciones disponibles

Documentación técnica de las plataformas y APIs de **Ruijie Networks** (incluida la línea **Reyee**) distribuidas por **SYSCOM**.

> **Sobre la marca.** Ruijie Networks Co., Ltd. es un fabricante de infraestructura de red: switches, puntos de acceso (AP) WiFi, gateways y routers, tanto para empresa como para PyME (línea **Reyee**). Su plataforma de gestión en la nube, **Ruijie Cloud**, administra de forma centralizada dispositivos de múltiples sitios con provisión *zero-touch*, monitoreo, autenticación de usuarios y portales cautivos.

## Plataformas

| Plataforma | Descripción | Estado |
| ---------- | ----------- | ------ |
| [Ruijie Cloud](./Ruijie-Cloud/README.md) | API REST de la nube de Ruijie/Reyee para gestión de dispositivos (AP, Switch, Gateway), redes WiFi, cuentas y vouchers de portal cautivo, y monitoreo de clientes y tráfico desde plataformas de terceros (MSP/CRM/ERP) | ✅ Disponible |
